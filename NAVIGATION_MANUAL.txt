A1. MAIN NAVIGATION BAR
--------------------------------------------------------------------------------

The navigation bar appears at the top of every page. On desktop it shows all
links. On mobile, tap the three-bar (hamburger) icon to open the side drawer.

  +---------------------------+--------------------------------------------------+
  | NAV LINK                  | WHAT IT DOES                                     |
  +---------------------------+--------------------------------------------------+
  | Home                      | Returns to the homepage (index.php)              |
  | About                     | Opens the About page                             |
  | Services  (has dropdown)  | Opens the Services page; hover to see sections   |
  | Resources (has dropdown)  | Online Resources or Library Holdings sub-pages   |
  | Guidelines                | Opens the library rules & policies page          |
  | Programs                  | Opens Programs & Events listing                  |
  | More      (has dropdown)  | Linkages, Library Survey, Administration         |
  +---------------------------+--------------------------------------------------+

  SERVICES dropdown items:
    - Circulation    → jumps to the Circulation tab
    - Reserve        → jumps to the Reserve tab
    - Reference      → jumps to the Reference tab
    - Filipiniana    → jumps to the Filipiniana tab
    - Periodical     → jumps to the Periodical tab

  RESOURCES dropdown items:
    - Online Resources  → resources.php (databases & e-resources)
    - Library Holdings  → holdings.php  (physical collection catalog)

  MORE dropdown items:
    - Linkages         → linkages.php      (institutional partnerships)
    - Library Survey   → survey.php        (embedded Google Form survey)
    - Administration   → administration.php (library personnel/org chart)

  MOBILE DRAWER (tap the hamburger icon):
    Shows all pages in a flat list — Home, About, Services, Online Resources,
    Library Holdings, Guidelines, Programs & Events, Linkages, Library Survey,
    Administration.

B1. LOGGING IN
--------------------------------------------------------------------------------

  1. Open http://localhost/library-website1/admin/login.php
  2. Enter your username and password.
  3. After 5 failed attempts, your IP is locked out for 15 minutes.
  4. On success you land on the Dashboard (admin/index.php).
  5. Sessions expire after 2 hours of inactivity — you will be redirected
     to the login page and must sign in again.

  To log out:
    Click "Log Out" at the bottom of the sidebar, or go to admin/logout.php.

B4. MEDIA MANAGER  (admin/media.php)
--------------------------------------------------------------------------------

  Overview stats at top:
    Total files, Images count, Videos count, Total size on disk.

  Filter bar:
    - Search by filename
    - Filter by type (Images / Videos)
    - Filter by folder (arrivals, personnel, programs, etc.)

  Media grid:
    - Thumbnail for images, film-icon for videos
    - Click a thumbnail → copies the file URL to clipboard (toast notification)
    - Eye icon  → opens the file in a new browser tab
    - Trash icon → deletes the file (confirms before deleting)

  Upload button (top right):
    - Choose a destination folder from the dropdown
    - Select a file (or drag & drop into the zone)
    - Images are automatically cropped to that folder's fixed dimensions
    - Videos up to 100 MB are accepted (MP4, WEBM, OGV)
    - After upload, the page refreshes and the new file appears in the grid

  Folder crop dimensions reference:
    arrivals  : 300 × 400 px  (portrait book cover)
    personnel : 400 × 400 px  (square staff photo)
    programs  : 800 × 450 px  (16:9 event photo)
    resources : 300 × 300 px  (square logo)
    featured  : 800 × 600 px  (4:3 spotlight)
    services  : 720 × 480 px  (3:2 section photo)
    about     : 800 × 500 px  (timeline / banner)
    media     : no crop       (general uploads)

  "Pick from Media Library" modal:
    Available on every image field across all admin pages. Click the
    "Browse" button next to any image URL field to open this modal.
    Use the search and filter controls to find the file, then click its
    thumbnail to insert the URL into the field automatically.

B16. COMMON ADMIN INTERACTIONS
--------------------------------------------------------------------------------

  Adding items
    Click the "Add [Item]" button in the top-right corner of any list page.
    A modal dialog slides in. Fill in the required fields (marked with *).
    Click the "Save" button inside the modal. The page reloads with a green
    success banner at the top confirming the save.

  Editing items
    Click the pen (edit) icon on any table row. The same modal reopens with
    all existing data already filled in. Make your changes and save.

  Deleting items
    Click the red trash icon. A browser confirmation dialog appears:
    "Are you sure?" — click OK to confirm, Cancel to abort.
    Deletes are permanent and cannot be undone.

  Image Upload Zones
    Click inside the dashed upload zone or drag a file onto it.
    A preview appears. The file is not saved until you submit the form.
    Images are automatically resized and center-cropped to the folder's
    fixed template dimensions (see Media Manager section for the sizes).

  Browse Media Library button
    Next to most image URL fields there is a "Browse" button.
    Click it to open the media picker modal. Use the search/filter controls,
    then click any thumbnail to select it. The URL is inserted automatically.

  Flash messages
    Green banner = success (auto-dismisses after 4 seconds)
    Red banner   = error (stays until dismissed or page reloads)

  CSRF protection
    All forms include a hidden security token. If you open the same form in
    two browser tabs and submit the older one, you may see "Invalid CSRF token."
    Simply refresh the page and try again.

  Session timeout
    After 2 hours without activity, the session expires. Any unsaved work will
    be lost. You will be redirected to the login page automatically.

B17. DATA FILE LOCATIONS (for reference / backup)
--------------------------------------------------------------------------------

  All content is stored as human-readable JSON files in the /data/ folder.

  data/settings.json          — site title, tagline, contact info, social links
  data/arrivals.json          — new arrival cards
  data/featured.json          — featured / spotlight resource
  data/about.json             — VGMO, schedule, timeline events
  data/services.json          — service tabs and their items
  data/guidelines.json        — library rules accordion items
  data/programs.json          — programs & events with photos
  data/linkages.json          — partner cards, MOU text, CTA text
  data/holdings.json          — physical collection catalog
  data/resources.json         — online database cards
  data/personnel.json         — staff profiles
  data/admin_credentials.json — admin username and bcrypt password hash

  Uploaded media files are stored in:
  assets/uploads/arrivals/    — book cover images (300×400)
  assets/uploads/personnel/   — staff photos (400×400)
  assets/uploads/programs/    — event photos (800×450)
  assets/uploads/resources/   — database logos (300×300)
  assets/uploads/featured/    — spotlight images (800×600)
  assets/uploads/services/    — service section photos (720×480)
  assets/uploads/about/       — timeline/banner images (800×500)
  assets/uploads/media/       — general uploads (no crop)

  To back up all content: copy the /data/ folder and the /assets/uploads/ folder.
  To restore: replace those two folders with your backup copies.
